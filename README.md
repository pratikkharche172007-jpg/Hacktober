# 🚀 Nova 360 AI

### Your AI-Powered Learning and Career Assistant

Nova 360 AI is an AI-powered assistant designed to help students with learning, programming, project development, and career planning. It combines a web-based chat interface with a Python backend and a locally running Large Language Model (LLM) to generate helpful, interactive responses.

The project aims to evolve into a personalized **AI Career Copilot** that helps students identify learning goals, explore technical skills, and plan their career journeys.

## ✨ Key Features

- 🤖 **AI-Powered Chat:** Ask questions and receive AI-generated responses.
- 💻 **Programming Assistance:** Get explanations of programming concepts and coding topics.
- 🎯 **Career Guidance Vision:** Designed to expand into personalized student career planning.
- 🧠 **Local AI Integration:** Runs the Llama model locally through Ollama.
- ⚡ **FastAPI Backend:** Provides API endpoints for communication between the frontend and AI model.
- 🌐 **Web-Based Interface:** Interact with the assistant through a browser.
- 💸 **Cost-Conscious Architecture:** No paid external AI API is required for the current local model setup.
- 🛠️ **Expandable Design:** Can be extended with additional student-focused features.
